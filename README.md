# TSB — متجر بيع المواقع الجاهزة

موقع عربي ثابت (HTML/CSS/JavaScript) بلا قاعدة بيانات، جاهز للنشر على GitHub Pages. طلبات الشراء والتواصل تفتح واتساب برسالة جاهزة، وروابط إنستغرام تفتح الحساب مباشرة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع `index.html` و`README.md` ومجلد `assets` كاملًا إلى جذر المستودع، مع الحفاظ على المجلدات الفرعية للصور.
3. من **Settings → Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages نفسها.

لا يحتاج الموقع إلى تشغيل build أو إعداد قاعدة بيانات. تعديلات المنتجات والأسعار تُجرى مباشرة في بطاقات المنتجات داخل `index.html`.
